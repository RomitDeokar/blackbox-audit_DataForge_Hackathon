# Confirmation-Safe Commit Mechanism

**Status: not yet designed.** This document is a placeholder.

The confirmation-safe commit mechanism (referenced by `REQUIREMENTS.md`
FR-3.2) — the design that guarantees a dispatch action is only finalized
once there is sufficient confirmed evidence the caller received the
critical confirmation, with no contradicting input beforehand — will be
designed and documented here in a later phase, along with its named states
and transitions.
